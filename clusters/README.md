## 建立一个 Paper Trail

1. 复制 `TEMPLATE.md`，取一个围绕问题的文件名，例如 `hhc-continuity-of-care.md` 或 `llm-guided-routing.md`。
2. 起点论文，也就是“为什么把这些文章放在一起”。起点是这个话题的入口。
3. 在群成员表中添加相关论文。每篇用群内编号 P0、P1、P2 标识；P0 是起点。
4. 去仓库 **Issues → New issue → Paper Trail 讨论**，填入这个 Paper Trail 页面的链接并提交。

## 文章之间可以是什么关系
eg：

| 关系 | 如何说明 |
| --- | --- |
| 前置工作 | 哪个模型、假设或方法构成基础？ |
| 后续延伸 | 放宽了什么假设，增加了什么机制或约束？ |
| 方法借鉴 | 哪项技术可以迁移过来？ |
| 对照 / 不同结论 | 在相近问题上，结论或证据有什么不同？ |
| 场景迁移 | 同类问题在另一场景中如何出现？ |
