## 收藏文章

把 PDF 放进相关的话题文件夹，再在该文件夹的 README 表格加一行；也可以只收藏 DOI、arXiv 或论文主页链接。文件名建议用 `年份-第一作者-短标题.pdf`。

方法使用 [METHODS.md](METHODS.md) 中的名称，可多选。矩阵的每个交叉格都是文件夹入口，在对应文件夹的文献表中添加文章即可。同一篇文章可出现在多个方法文件夹，PDF 只保存一份。

## Paper Trail

以某篇文章为起点建立一个 [Paper Trail](clusters/README.md)。文件夹内可以放它的前置工作、后续延伸、相关工作，以及我们自己的共同疑问。

每个 Paper Trail 设有一个 Issue 评论区。
