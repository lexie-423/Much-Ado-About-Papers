## 收藏一篇

把 PDF 放进最相关的话题文件夹，再在该文件夹的 README 表格加一行；也可以只收藏 DOI、arXiv 或论文主页链接。文件名建议用 `年份-第一作者-短标题.pdf`。

一篇论文只存一份，跨话题时从其他目录链接到同一份文件。以居家医疗或护理为主要场景的文章，优先放入 Home Healthcare，再标注路径、调度等问题关键词。

方法使用 [METHODS.md](METHODS.md) 中的名称，可多选。觉得值得横向比较的文章，也可以把链接加进“话题 × 方法”矩阵；不用为了收藏一篇论文填完所有格子。

## 从一篇到一群

遇见一篇值得顺藤摸瓜的文章，就以它为起点建立一个 [Paper Trail](clusters/README.md)。群里可以放它的前置工作、后续延伸、相似方法、不同结论，以及我们自己的共同疑问。

每个 Paper Trail 有一个 Issue 评论区。大家可以讨论整个方向，也可以点名群中的某一篇；无需给每篇论文单独建 Issue。

慢慢收集，随时翻找。
